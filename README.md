# Smart Swing Timers
An extremely light-weight addon for World of Warcraft that shows and hides the default UI swing timers according to which type of auto-attack was last performed.

So far it has been tested and works on Patch 1.60.01 of Forever

## Installing
To install this addon simply go to [the page for the latest release](https://github.com/fabriond/SmartSwingTimers/releases/latest) and download the SmartSwingTimers.zip and extract it into your WoW addons folder.
